<h1 align="center">🚤 Carter's Lake Visitor Center Boating Safety Game 🚤</h1>

An educational touchscreen game developed for the U.S. Army Corps of Engineers and the Carters Lake Visitor Center to help visitors learn essential boating safety concepts through an interactive game experience.

The project combines side-view and top-down gameplay, life jacket and boating item selection activities, navigation challenges, quizzes, scoring, and feedback systems to reinforce safe boating behavior in a memorable and engaging way.

## Project Overview

Boating safety education can be more effective when learners interact with the material instead of only reading static instructions. This project explores how a touchscreen kiosk game can present boating safety concepts in a way that is accessible, engaging, and appropriate for young visitors at the Carters Lake Visitor Center.

The game is designed for a Windows-based offline kiosk and uses large touchscreen controls, simple language, mascot-guided prompts, and interactive learning reinforcement to support a wide youth audience.

## Research Questions

- How effectively can an interactive touchscreen game improve engagement with boating safety concepts for students and youth visiting the Carters Lake Visitor Center?
- How well do multiple game scenarios support player understanding, usability, and task completion in an educational boating safety game?
- How successfully can an offline, touchscreen-only kiosk design deliver an intuitive and accessible educational experience for a wide youth audience?

## Features

- Character selection
- Life jacket safety activity
- Boating item selection activity
- Tutorial guidance
- Top-down boat navigation
- Obstacle avoidance
- Quiz-based learning checks
- Score tracking
- Collision handling
- Feedback and retry loops
- Kiosk-friendly touchscreen interface
- Mascot-guided prompts for younger players

## Gameplay Flow

The core gameplay flow includes:

1. Character selection
2. Life jacket safety selection
3. Boating item selection
4. Tutorial guidance
5. Top-down boating navigation
6. Obstacle avoidance
7. Quiz and scoring elements
8. Feedback and retry opportunities

This structure allows players to learn boating safety concepts through repeated interaction, decision-making, and immediate feedback.
